# Manifiesto de evidencias privadas — PFC Entrega 1

Las evidencias originales (carta de aceptación firmada, registros de contacto,
audios, consentimientos firmados) **no se publican** en este repositorio porque
contienen datos personales de terceros (LOPDP). Se custodian en la carpeta
institucional privada del equipo (cuenta `@uteq.edu.ec`), compartida con el
docente.

Este manifiesto registra cada archivo privado para que su integridad pueda
verificarse con su huella SHA-256.

## Cómo calcular la huella

En PowerShell:

```
Get-FileHash .\nombre-del-archivo.pdf -Algorithm SHA256
```
